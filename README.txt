وصلني - حزمة بناء APK من الهاتف عبر GitHub Actions

هذه الحزمة تحوّل نموذج الويب الحالي إلى تطبيق Android تجريبي APK عبر بناء سحابي مجاني باستخدام GitHub Actions.

مهم:
- النسخة الحالية نموذج واجهات تجريبي وليست نظام توصيل متكاملاً.
- لا يوجد خادم أو حسابات حقيقية أو طلبات فعلية حتى الآن.
- الدفع في التصور الحالي: كاش عند الاستلام فقط.

الخطوات من هاتف Android:
1) افتح https://github.com وسجّل الدخول أو أنشئ حساباً.
2) اضغط + ثم New repository.
3) سمّ المستودع wasalni واتركه Public لتسهيل أول تجربة، ثم Create repository.
4) من صفحة المستودع اختر Add file ثم Upload files.
5) فك ضغط هذا الملف على الهاتف أولاً، ثم ارفع كل الملفات والمجلدات الموجودة داخل مجلد wasalni_prototype إلى جذر المستودع. يجب أن يظهر package.json وcapacitor.config.json ومجلد .github.
6) اضغط Commit changes.
7) افتح تبويب Actions. اختر Build Wasalni APK ثم Run workflow إذا لم يبدأ البناء تلقائياً.
8) انتظر حتى تظهر علامة نجاح خضراء، افتح عملية البناء، وانزل إلى Artifacts.
9) نزّل wasalni-debug-apk.zip، فك ضغطه، ثم افتح app-debug.apk وثبّته.

إذا لم يظهر مجلد .github عند رفع الملفات، فعّل إظهار الملفات المخفية في مدير الملفات أو ارفع المشروع عبر متصفح يدعم الملفات المخفية.
